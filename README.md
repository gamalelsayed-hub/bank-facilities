# إدارة التسهيلات البنكية

تطبيق سطح مكتب لويندوز لمتابعة التسهيلات البنكية: حدود البنوك، القروض القصيرة والطويلة، الاعتمادات المستندية وتمويلها، جداول السداد، وتنبيهات الاستحقاق. يعمل بدون إنترنت.

## التحميل والتشغيل
1. من صفحة **Releases** حمّل `BankFacilities-Windows.zip`.
2. فك الضغط في مكان ثابت (مثل `C:\BankFacilities`) وشغّل `BankFacilities.exe`.
3. أول مرة قد يظهر تحذير SmartScreen: اضغط **More info** ثم **Run anyway**.

## الشاشات
| الشاشة | الوظيفة |
|---|---|
| لوحة المتابعة | الحدود (المستخدم/المتاح/النسبة)، التنبيهات، سلم الاستحقاقات، تكلفة التمويل لكل بنك، القروض الطويلة |
| الاستحقاقات والتنبيهات | المستحق خلال فترة أو شهر محدد أو المتأخر، مع زر سداد وتصدير Excel (xlsx) |
| قرض / تمويل جديد | البنك والتسهيل يعبّئان الشروط تلقائياً، معاينة الجدول، تحذيرات تجاوز الحد والشروط |
| تسجيل سداد | سداد قسط كامل/جزئي، سداد مبكر، تحويل اعتماد إلى تمويل اعتماد |
| سجل القروض | بحث وفلترة، جدول كل قرض وحركاته، إلغاء حركة، كشف قرض PDF |
| تقرير القروض بالبنك | لكل بنك: القروض، أصل القرض، المسدد، المستخدم حتى تاريخه، المتبقي مع الربح، المتأخر، مع إجمالي كل بنك والإجمالي العام |
| البنوك والشروط | البنوك والتسهيلات وكل شروطها، مع سجل تعديلات |
| الإعدادات | العملات، المؤشرات (سايبور…)، العطل، أنواع التسهيلات، طرق الدفع، حقول إضافية، مجلد البيانات والنسخ الاحتياطي |

الطباعة وحفظ PDF متاحة في لوحة المتابعة والاستحقاقات وسجل القروض والتقرير وكشف كل قرض. زر «رجوع» (أو Alt + ←) يعود للشاشة السابقة.

كل الشروط والقوائم قابلة للتعديل من داخل البرنامج بدون تعديل برمجي. القروض المسجلة تحتفظ بالشروط التي فُتحت عليها.

## البيانات
- **المستودع لا يحتوي أي بيانات.** البيانات تبقى على جهازك فقط.
- ملف واحد: `المستندات\إدارة التسهيلات البنكية\facilities-data.json`، مع نسخة احتياطية يومية في `backups`.
- أول تشغيل يبدأ فارغاً. لإدخال بياناتك: **الإعدادات ← حفظ نموذج الاستيراد الفارغ**، املأه، ثم **استيراد من ملف Excel**. تظهر معاينة بالأعداد والأخطاء قبل الحفظ.

### نموذج الاستيراد (`app/template.xlsx`)
| الورقة | المحتوى |
|---|---|
| البنوك والحدود | صف لكل تسهيل: البنك، اسم التسهيل، النوع، الحد، بدون سقف، حد فرعي من، العملة، أقصى مدة، مدة الاعتماد، يتحول إلى تسهيل |
| القروض | صف لكل قسط: البنك، التسهيل، البيان، المرجع، رقم الاعتماد، تاريخ البداية والاستحقاق، الأصل، الربح، المسدد، العملة، سعر الصرف، أجل القرض |

الصفوف التي لها نفس البنك ونفس البيان تُجمع في قرض واحد.
- للعمل من أكثر من جهاز: اختر مجلداً مشتركاً من الإعدادات ← تغيير مجلد البيانات.

## هيكل الكود
```
app/
  main.js       العملية الرئيسية: النافذة، قراءة/كتابة ملف البيانات، النسخ الاحتياطي، الإشعارات
  preload.js    الجسر الآمن بين الواجهة والعملية الرئيسية
  index.html    الواجهة كاملة (HTML/CSS/JS بدون مكتبات خارجية)
  template.xlsx نموذج استيراد البيانات من Excel
build-windows.sh  يبني نسخة ويندوز محمولة في dist/
```

## إصدار نسخة جديدة
1. ارفع رقم `version` في `app/package.json` (مثلاً من 1.2.0 إلى 1.3.0).
2. من تبويب **Actions** ← «بناء نسخة ويندوز ونشرها» ← **Run workflow**، واكتب ملاحظات الإصدار.
3. يُنشر الإصدار باسم `v1.3.0`، ويظهر للمستخدمين عند الضغط على «فحص التحديثات» داخل البرنامج، فينزّلونه ويثبّتونه بضغطة واحدة.

> الإصدارات تُنشر أيضاً في المستودع العام `bank-facilities-releases` (ملفات التنزيل فقط، بدون كود) عند وجود المفتاح `RELEASES_TOKEN` في Secrets. البرنامج يفحص التحديثات منه أولاً، فلا يحتاج أي جهاز رمز وصول، ويبقى هذا المستودع خاصاً.

للبناء على جهازك:
```bash
./build-windows.sh
```
يحمّل Electron 31.7.7 لويندوز من GitHub ويضع التطبيق داخله. الناتج: `dist/BankFacilities-Windows.zip`.

للتشغيل أثناء التطوير (يتطلب Node.js):
```bash
npx electron@31.7.7 app
```
